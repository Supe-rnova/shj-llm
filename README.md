# shj-llm

Administering the Shepard, Hovland & Jenkins (1961) category learning
task to large language models as experimental subjects.

Stage 1: behavioural. Run the six SHJ category structures, report the
difficulty ordering, compare against human baselines.

Stage 2 (conditional): fit exemplar and prototype models to the model's
own trial-level choices and recover attention weights.

Status: pilot.
